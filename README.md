# نرم‌افزار مدیریت مالی پروژه‌های شخصی

> **نسخه ۱.۰.۰** · ساخته‌شده طبق سند PRD و UI Kit

## معرفی

اپلیکیشن مدیریت مالی پروژه‌های شخصی — یک نرم‌افزار **کاملاً فرانت‌اند** و **بدون بک‌اند** برای مدیریت مالی پروژه‌هایی که کاربر (به‌همراه شرکایش) از کارفرماها دریافت می‌کند.

### ویژگی‌های کلیدی

- ✅ **مدیریت کارفرماها و شرکا** با تراز زنده بدهکار/بستانکار
- ✅ **مدیریت پروژه‌ها** با مبلغ ثابت، وضعیت، تاریخ شروع/پایان، سهم درصدی هر شریک، رنگ و pinned
- ✅ **ثبت دریافتی** با تخصیص به چند پروژه + مدیریت مازاد به‌عنوان علی‌الحساب کارفرما (EmployerCredit)
- ✅ **هزینه‌های مستقل از پروژه** — هر هزینه به‌طور مستقل ثبت و بین شرکا تقسیم می‌شود
- ✅ **توزیع سهم هزینه** بین شرکا به‌صورت درصد یا مبلغ، با دکمه «تقسیم مساوی» و اعتبارسنجی مجموع
- ✅ **ویرایش و حذف تراکنش‌ها** (دریافتی، هزینه، انتقال) از طریق bottom sheet و تأیید حذف
- ✅ **انتقال داخلی بین شرکا** با ثبت تاریخچه مستقل
- ✅ **فعالیت روزانه** (چه پروژه‌ای، چه شرکایی، چه ساعاتی) بدون تأثیر مالی
- ✅ **ثبت ابزارآلات** با مالکیت + خروجی PDF لیست ابزارآلات
- ✅ **گزارش‌گیری زنده**: تراز کارفرماها، تراز شرکا، جریان نقدی ماهانه/سالانه، خروجی JSON
- ✅ **فیلتر تاریخ** در گزارش‌های کارفرماها و جریان نقدی (همین ماه / همین سال / بازه دلخواه)
- ✅ **خروجی PDF تراز کارفرما** برای ارائه به کارفرما
- ✅ **داشبورد** با وضعیت کلی، پروژه‌های فعال، تراکنش‌های اخیر، بدهکاران برتر
- ✅ **بکاپ/بازگردانی** JSON کامل
- ✅ **Onboarding** ۳ مرحله‌ای برای اولین بار
- ✅ **تم تیره** با فونت فارسی Vazirmatn و آیکن‌های Lucide
- ✅ **تقویم شمسی** و اعداد فارسی در تمام رابط

## استک فنی

- **HTML5** + **CSS3** + **JavaScript (ES2020+)**
- **Vite 6** (dev server + build tool)
- **Tailwind CSS v4** (CSS-first config)
- **lucide** (آیکن‌ها)
- **jalaali-js** (تقویم شمسی)
- **IndexedDB** + **localStorage** (ذخیره‌سازی — بدون بک‌اند)

## نصب و اجرا

```bash

npm install

# اجرای dev server
npm run dev

# build production
npm run build

# preview build production
npm run preview
```

سپس مرورگر را روی `http://localhost:5173/` باز کنید.

## مدل داده

### موجودیت‌های اصلی (در IndexedDB)

| موجودیت | توضیح |
|---|---|
| **Employer** | کارفرما — نام، شماره تماس، یادداشت، رنگ آواتار |
| **Partner** | شریک — نام، شماره تماس، ایمیل، یادداشت، رنگ آواتار |
| **Project** | پروژه — عنوان، کارفرما، مبلغ، تاریخ شروع/پایان، وضعیت، رنگ، pinned |
| **ProjectShare** | سهم شریک در پروژه — projectId، partnerId، percentage |
| **Receipt** | دریافتی — کارفرما، دریافت‌کننده، مبلغ، تاریخ، یادداشت |
| **ReceiptAllocation** | تخصیص دریافتی به پروژه‌ها — receiptId، projectId، amount |
| **EmployerCredit** | علی‌الحساب کارفرما — employerId، amount، sourceReceiptId |
| **Expense** | هزینه مستقل — عنوان، مبلغ، paidByPartnerId، تاریخ، یادداشت، shareDistribution |
| **PartnerTransfer** | انتقال بین شرکا — fromPartnerId، toPartnerId، amount، تاریخ، یادداشت |
| **DailyActivity** | فعالیت روزانه — date، projectId، partnerId، startTime، endTime |
| **Equipment** | ابزار — نام، ownerPartnerId، purchaseDate، amount |

> `Expense.shareDistribution` آرایه‌ای از `{ partnerId, amount }` است که سهم هر شریک از هزینه را به تومان مشخص می‌کند.

### تنظیمات (در localStorage)

- `settings`: userName، avatarColor، onboardingCompleted، autoBackup، ...
- `customOrders`: ترتیب سفارشی کارفرماها، شرکا، پروژه‌ها

## ناوبری

### نوار پایین (۴ دکمه + FAB مرکزی)
- 🏠 **خانه** — داشبورد
- 💼 **پروژه‌ها** — لیست پروژه‌ها بر اساس وضعیت
- ➕ **(FAB مرکزی)** — ثبت تراکنش (دریافتی/هزینه/انتقال)
- 📅 **فعالیت** — فعالیت روزانه
- 📊 **گزارش** — گزارش‌ها

### منوی همبرگری بالا
- کارفرماها
- شرکا
- ابزارآلات
- بکاپ و بازگردانی
- تنظیمات (پروفایل کاربر)

## ماژول‌ها

| ماژول | توضیح |
|---|---|
| **داشبورد** | خلاصه تراز، پروژه‌های فعال، تراکنش‌های اخیر، بدهکاران برتر |
| **پروژه‌ها** | لیست پروژه‌ها با فیلتر وضعیت، سهم شرکا، progress bar |
| **تراکنش‌ها** | لیست یکپارچه دریافتی/هزینه/انتقال + ویرایش و حذف |
| **ثبت دریافتی** | ۲ مرحله‌ای: اطلاعات پایه + تخصیص به پروژه‌ها (با تخصیص خودکار و علی‌الحساب) |
| **ثبت هزینه** | فرم مستقل با توزیع سهم بین شرکا (٪ یا مبلغ) + تقسیم مساوی |
| **انتقال بین شرکا** | از شریک X به شریک Y با مبلغ و تاریخ |
| **فعالیت روزانه** | ثبت ساعت‌کاری شریک روی پروژه (بدون تأثیر مالی) |
| **ابزارآلات** | لیست ابزار با مالکیت + خروجی PDF |
| **گزارش‌ها** | ۴ تب: تراز کارفرماها، تراز شرکا، جریان نقدی، خروجی JSON + فیلتر تاریخ + PDF کارفرما |
| **بکاپ** | خروجی JSON / بازگردانی / بکاپ خودکار / پاک‌سازی داده‌ها |
| **تنظیمات** | ویرایش پروفایل و رنگ آواتار |

## استفاده

1. اولین بار: onboarding ۳ مرحله‌ای (خوش‌آمد → معرفی مفاهیم → وارد کردن نام)
2. ایجاد کارفرما (از منوی همبرگری → کارفرماها)
3. ایجاد شریک (از منوی همبرگری → شرکا)
4. ایجاد پروژه با سهم شرکا (از صفحه پروژه‌ها → FAB)
5. ثبت دریافتی از کارفرما (از FAB مرکزی → تراکنش → دریافتی)
6. ثبت هزینه با توزیع سهم (از FAB مرکزی → تراکنش → هزینه)
7. ثبت انتقال بین شرکا (از FAB مرکزی → تراکنش → انتقال)
8. ویرایش/حذف هر تراکنش با کلیک روی آیتم یا دکمه حذف
9. مشاهده گزارش‌ها و فیلتر تاریخ (از نوار پایین → گزارش)
10. بکاپ‌گیری (از منوی همبرگری → بکاپ و بازگردانی)
