# نرم‌افزار مدیریت مالی پروژه‌ها

اپلیکیشن فارسی برای مدیریت مالی پروژه‌ها، کارفرماها و شرکا. رابط کاربری با JavaScript خام ساخته شده و نسخه فعلی از حساب‌های محلی چندگانه در مرورگر پشتیبانی می‌کند.

## معرفی

این برنامه به افراد و گروه‌های کوچک کاری کمک می‌کند پروژه‌ها، دریافتی‌ها، هزینه‌ها، سهم شرکا و وضعیت تسویه‌های مالی را در یک محیط یکپارچه ثبت و پیگیری کنند.

**وضعیت معماری فعلی:** برنامه همچنان Local-first است. هر حساب محلی فضای IndexedDB و تنظیمات جداگانه‌ای دارد. اطلاعات حساب‌ها و نشست در localStorage ذخیره می‌شوند. داده‌ها بین مرورگرها یا دستگاه‌های مختلف همگام‌سازی نمی‌شوند و هنوز سرور یا پایگاه داده مرکزی وجود ندارد.

## قابلیت‌ها

### مدیریت پروژه و طرف‌های مالی
- ثبت و مدیریت کارفرماها و شرکا
- تعریف پروژه با کارفرما، تاریخ‌ها، رنگ، یادداشت و سهم درصدی شرکا
- ثبت مبلغ پروژه یا مشخص‌کردن اینکه مبلغ هنوز نامشخص است
- دسته‌بندی پروژه‌ها به فعال و تکمیل/بایگانی
- نمایش پروژه‌های بایگانی‌شده در یک بخش جمع‌شونده
- ذخیره و استفاده مجدد از قالب پروژه

### تراکنش‌ها و هزینه‌ها
- ثبت دریافتی از کارفرما و تعیین شریک دریافت‌کننده
- تخصیص یک دریافتی به یک یا چند پروژه
- محاسبه مازاد دریافتی و اعتبار کارفرما
- ثبت هزینه و تعیین پرداخت‌کننده و سهم هر شریک
- تقسیم هزینه بر اساس درصد یا مبلغ و تقسیم مساوی
- ثبت انتقال مالی بین شرکا
- مشاهده، ویرایش و حذف تراکنش‌های ثبت‌شده
- نمایش مبالغ با جداکننده هزارگان و معادل نوشتاری فارسی در فرم‌های پشتیبانی‌شده

### تسویه و گزارش‌ها
- محاسبه مانده حساب کارفرماها
- محاسبه سهم پروژه و وضعیت دریافتی هر شریک
- محاسبه مطالبات و بدهی‌های بین شرکا با درنظرگرفتن هزینه‌ها و انتقال‌ها
- نمایش خلاصه بدهی بین شرکا در داشبورد
- گزارش جریان نقدی در بازه‌های زمانی
- خروجی JSON برای گزارش‌ها و پشتیبان‌گیری
- خروجی PDF برای گزارش کارفرما و فهرست ابزارآلات

### امکانات تکمیلی
- داشبورد با خلاصه وضعیت پروژه‌ها، تراکنش‌های اخیر و یادآوری‌ها
- جستجوی سراسری
- ثبت فعالیت روزانه شرکا روی پروژه‌ها
- ثبت ابزارآلات و مالکیت آن‌ها
- پروفایل محلی شامل نام و آواتار قابل تنظیم
- ثبت‌نام و ورود محلی با ایمیل و رمز عبور
- تغییر رمز عبور و خروج از حساب
- جداسازی فضای داده هر حساب در همان مرورگر
- پشتیبان‌گیری و بازیابی اطلاعات با فایل JSON
- رابط فارسی، راست‌چین، تقویم شمسی و فونت محلی Vazirmatn

## فناوری‌ها

- HTML5
- CSS3 و Tailwind CSS v4
- JavaScript خام (ES Modules)، بدون React، Vue یا فریم‌ورک رابط کاربری
- Vite 6 برای سرور توسعه و ساخت نسخه نهایی
- IndexedDB برای داده‌های اصلی
- localStorage برای حساب‌های محلی، نشست، تنظیمات و ترجیحات
- Web Crypto API (PBKDF2 / SHA-256) برای ذخیره هش‌شده رمز عبور
- Lucide برای آیکن‌ها
- jalaali-js برای تبدیل تاریخ‌های شمسی و میلادی
- Sharp برای اسکریپت تولید آیکن‌ها

## پیش‌نیازها

- Node.js و npm
- مرورگر به‌روز مانند Chrome، Edge، Firefox یا Safari

## نصب و اجرا

ابتدا مخزن را دریافت کنید و وارد پوشه پروژه شوید:

```bash
git clone https://github.com/MohsenFakori/pfm-aa.git
cd pfm-aa
npm install
```

اجرای سرور توسعه:

```bash
npm run dev
```

برای دسترسی از دستگاه‌های دیگر در شبکه محلی یا رفع برخی مشکلات اتصال localhost می‌توانید اجرا کنید:

```bash
npm run dev -- --host 127.0.0.1
```

ساخت نسخه production:

```bash
npm run build
```

پیش‌نمایش نسخه ساخته‌شده:

```bash
npm run preview
```

در حالت پیش‌فرض Vite آدرس توسعه معمولاً `http://localhost:5173/` است.

## فرمان‌های npm

| فرمان | کاربرد |
|---|---|
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت خروجی production در پوشه `dist` |
| `npm run preview` | پیش‌نمایش خروجی production |

در حال حاضر اسکریپت مستقل lint یا تست خودکار در `package.json` تعریف نشده است.

## ذخیره‌سازی و پشتیبان‌گیری

- اطلاعات پروژه‌ها، کارفرماها، شرکا، دریافتی‌ها، تخصیص‌ها، هزینه‌ها، انتقال‌ها، فعالیت‌ها و ابزارآلات در IndexedDB ذخیره می‌شوند.
- تنظیمات پروفایل، ترتیب‌های سفارشی و برخی ترجیحات در localStorage قرار می‌گیرند.
- برای جلوگیری از ازدست‌رفتن اطلاعات، از بخش «بکاپ و بازگردانی» خروجی JSON تهیه کنید و فایل پشتیبان را در مکانی امن نگه دارید.
- پاک‌کردن داده‌های مرورگر یا استفاده از مرورگر/دستگاه دیگر می‌تواند دسترسی به داده‌های محلی را از بین ببرد؛ فایل پشتیبان را جداگانه نگهداری کنید.

## محدودیت‌ها و وضعیت توسعه

- برنامه در حال حاضر بک‌اند، پایگاه داده سروری یا همگام‌سازی ابری ندارد.
- اطلاعات هر مرورگر/دستگاه مستقل است.
- احراز هویت فعلی فقط محلی و مخصوص توسعه است؛ اطلاعات حساب و هش رمز عبور در localStorage مرورگر قرار دارند. رمز خام ذخیره نمی‌شود.
- هش رمز عبور با PBKDF2 و salt تصادفی ساخته می‌شود؛ بااین‌حال localStorage در برابر دسترسی کد مخرب همان مبدأ یا دسترسی مستقیم به مرورگر امن نیست.
- اولین حساب محلی از پایگاه داده پیشین `pfm_db` استفاده می‌کند تا داده‌های فعلی کاربر حفظ شوند؛ حساب‌های بعدی پایگاه داده جداگانه خواهند داشت.
- برای استفاده واقعی، احراز هویت باید به سرور منتقل شود، رمزها در سرور با الگوریتم مناسب مانند Argon2id یا bcrypt هش شوند و مجوز دسترسی در تمام APIها سمت سرور کنترل شود.
- حساب‌های محلی فعلی به‌معنای چندکاربری آنلاین نیستند؛ هر حساب فقط روی همان مرورگر و دستگاه قابل استفاده است.
- قابلیت‌های PWA و اجرای آفلاین باید جداگانه بررسی و آزمون شوند و در این README به‌عنوان قابلیت تضمین‌شده معرفی نشده‌اند.
- تست خودکار و lint در حال حاضر در اسکریپت‌های پروژه پیکربندی نشده‌اند.
